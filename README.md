# Stock Strength Alert GUI

Chinese UI: 個股三層轉強提醒

這是獨立於「關卡小白」的 Windows GUI，支援智伸科、台達電、緯穎、大立光、日月光投控、聯鈞、順達、世禾、均華、研華、緯創、世界先進、統一超、長榮航與是方；每檔股票各自使用自己的歷史日 K 與量價慣性。是方另列為低流動性觀察股。

## 開啟方式

雙擊桌面上的 `智伸科4551三層轉強提醒.lnk`，或雙擊 `啟動智伸科轉強提醒.bat`。

程式開啟時先讀本機快取，不會自動連線。盤後按「更新今日收盤＋Yahoo籌碼（每日一次）」會一次取得 Yahoo 最新日 K 與公開籌碼；同一天再次按下不會重抓網路。

GitHub／Streamlit Cloud 的入口檔是 `app.py`；手機開啟後選股票，再按同一個更新按鈕即可取得資料。

首頁是「午餐小抄」：在家盤後按一次「更新全部（盤後）」後，隔天直接開啟即可查看已保存的前一交易日操作重點、支撐、壓力、量比、ATR 與季線；首頁只讀快取，不會重新下載或跑歷史回測。按股票名稱才進入完整個股分析。

行情以 Yahoo 為主；若快取中有使用者提供的 CMoney 籌碼，CMoney 的法人、外資、大戶、散戶與趨勢欄位優先，Yahoo 公開籌碼只用來補 CMoney 沒提供的欄位，不會覆蓋 CMoney 判讀。

## 燈號

- 🟡 止跌跡象：不再連續創低、下跌量縮、殺低後收回，先觀察。
- 🟢 資金回流，可小試：低點墊高，且量價顯示承接；籌碼資料可用時會一併檢查。
- 🟢🟢 轉強確認：突破智伸科自身動態壓力並守住，量價與可取得籌碼同步時才標示完整確認。
- 🔴 判斷失敗／停加：再破動態支撐且已取得的籌碼顯示外流。

門檻由智伸科自己的歷史 ATR、量比分布、轉折週期、近期高低點動態產生，不使用固定股價門檻。

「可小試」是早期觀察訊號，不等於持股加碼許可；若現價仍在季線下，已持股仍先不加碼，等站回季線再評估。

程式會把操作分成兩條白話指引：空手看能不能小量試單；已持股看要不要保護庫存，不把兩者混成一路攤平。
